pmosh

Report a problem

From the app, or from the agent on the other end of your session.

Reports go to the developer only. Nothing is published, nothing is shared, there is no account and no tracking. Every report is read.

From the app

Settings → Report a problem. Type what went wrong and tap Send from pmosh. pmosh adds its version, your device model and iOS version, the transport (mosh or ssh), the network kind, and — with the switch on — the last lines of its own event log (connects, sizes, timings; never what is on your screen). Offline, it is queued and sent later.

From your agent

pmosh is mostly used to drive an agent such as Claude Code inside tmux. The agent on your host sees things you cannot put into words — resize storms, stray bytes in its input, tmux pauses — so it can file the report, with what it saw. Two ways in:

  1. Settings → Report a problem → Hand to your agent types a ready-made request into the active tab. Read it, press return; the agent does the rest.
  2. Ask the agent yourself. Inside a pmosh session these variables are set for new panes: PMOSH_CLIENT (for example pmosh/1.5.5 (iPhone16,1; iOS 26.6)), PMOSH_REPORT_URL, and PMOSH_REPORT_HOWTO (this page).

The protocol

HTTP, from any machine with curl:

curl -sS -X POST "$PMOSH_REPORT_URL" -H 'content-type: application/json' --data @- <<'JSON'
{"problem": "what went wrong, in one or two sentences",
 "steps":   "how to see it again",
 "context": "what you saw from the host side",
 "host_os": "Ubuntu 24.04", "tmux": "3.4"}
JSON

The answer is 201 {"id": "…", "status": "received"}. Plain-text bodies work too. The current URL is also published in report.json.

In-session, with no network needed on the host — the app picks the report out of the terminal stream and asks the person to send it:

printf '\e]1337;pmosh-report=%s\a' "$(printf '%s' '{"problem":"…","context":"…"}' | base64 | tr -d '\n')"

pmosh shows the report with a Send button, adds its own version, device, transport and network, and uploads it once tapped (queued until online). Nothing an agent prints leaves the phone by itself.

Fields, all optional except problem: problem expected steps context log host_os tmux shell agent tags contact. Limits: 64 KB per report, a dozen per hour per address.

What happens next

Reports land in a private inbox read by the developer's own tooling. Fixes ship through the App Store release notes. Leave a contact if you want to hear back; otherwise the fix is the answer.
